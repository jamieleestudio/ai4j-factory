# AI 驱动数据 — 整体逻辑与流程

## 1. 核心理念

传统：人找数据。AI 驱动：数据找人。

AI 作为数据与业务之间的操作系统，完成从理解意图到交付洞察的全链路闭环。

---

## 2. 三种能力

| 能力 | 触发方式 | 逻辑 | 场景 |
|------|---------|------|------|
| 主动查询 | 用户提问 | 意图 → 查询 → 交付 | "上季度销售额多少" |
| 主动推送 | 定时/事件 | 规则 → 检测 → 推送 | 指标异动告警 |
| 主动诊断 | 异常/追问 | 异常 → 归因 → 建议 | "为什么下降" |

```
业务意图 → 意图理解 ──→ 主动查询 / 主动推送 / 主动诊断
                         │
                     语义层（统一口径 / 权限 / 路由）
                         │
                     数据中台（ODS → DWD → DWS → ADS）
                         │
                     洞察交付（文字 + 表格 + 图表 + 建议）
```

---

## 3. 主流程

```
输入 ──→ 意图理解 ──→ 语义解析 ──→ 查询执行 ──→ 洞察生成 ──→ 交付
```

| 步骤 | 输入 | 输出 | 关键逻辑 |
|------|------|------|---------|
| 意图理解 | 自然语言/事件 | 结构化意图 | 识别对象、时间、范围 |
| 语义解析 | 结构化意图 | 合法查询参数 | 映射语义层，注入权限 |
| 查询执行 | 合法参数 | 原始数据 | 路由到最简数据层 |
| 洞察生成 | 原始数据 | 可理解结论 | 解读、选图表、给建议 |
| 交付 | 洞察内容 | 用户可感知结果 | 文字/表格/图表/告警/推送 |

意图不完整时追问，一次只问一个问题，优先级：主题 > 指标 > 时间 > 条件 > 维度。

---

## 4. 五要素框架

| 要素 | 含义 | SQL 映射 | 示例 |
|------|------|----------|------|
| 主题 | 看谁/看什么业务对象 | FROM | 客户、门店、商品 |
| 指标 | 看什么数 | SELECT 聚合 | 销售额、订单量 |
| 时间 | 看什么时候 | WHERE 时间 + GROUP BY 粒度 | 2024Q4，按月 |
| 条件 | 筛选哪些范围 | WHERE 筛选 | 华东区、电子产品 |
| 维度 | 按什么角度分组 | GROUP BY | 按区域、按产品线 |

核心约束：指标、时间、条件、维度必须属于同一主题。

---

## 5. 五要素能覆盖什么

### 按分析深度分级

| 级别 | 类型 | 覆盖 | 说明 |
|------|------|------|------|
| L1 | 描述性 — "是什么" | ✅ 100% | 单值、分组、趋势、占比 |
| L2 | 对比性 — "比怎样" | ⚠️ ~75% | 同比环比✅，两时段对比❌，与目标对比❌ |
| L3 | 诊断性 — "为什么" | ⚠️ ~30% | 单维下钻✅，归因分析❌，异常检测❌ |
| L4 | 预测性 — "会怎样" | ❌ 0% | 趋势预测、情景模拟 |

### 缺口与扩展

| 缺口 | 扩展方案 | 优先级 |
|------|---------|--------|
| Top N / 排名 | 加 orderBy + limit 字段 | 高 |
| 两时段对比 | timeRange 改为数组 | 高 |
| 指标过滤（HAVING） | filters 加 level 区分 WHERE/HAVING | 中 |
| 派生指标 | metrics 加 formula 字段 | 中 |
| 跨主题关联 | 多主题查询引擎或预关联宽表 | 低 |

**结论**：五要素原生覆盖约 60% 日常查询，加高优扩展（Top N + 两时段对比）后覆盖约 90%。诊断和预测需独立模块建设。

---

## 6. 语义层

语义层是 AI 与数据中台之间的契约。AI 不操作表和字段，只操作语义层定义的概念。

三个作用：

- **口径统一**：同一指标名只有一种计算方式
- **权限管控**：权限绑定在维度上，执行时自动注入过滤，AI 无感知
- **数据层路由**：优先 ADS → 必要时 DWS → 极端 DWD

---

## 7. 权限模型

- AI 永远看不到用户没权限的数据
- 权限在语义层注入，对 AI 透明
- 用户筛选与权限取交集；无交集则提示无权限；未指定筛选则用权限范围

---

## 8. 洞察生成

| 层次 | 内容 |
|------|------|
| 事实 | 数据本身 |
| 对比 | 与基准的差异 |
| 行动 | 基于对比的建议 |

主动查询交付事实和对比，主动诊断交付行动。

图表自动选择：时间序列→折线图，分类对比→柱状图，占比→饼图，排名→水平柱状图。

---

## 9. 演进路线

| 阶段 | 能力 | 里程碑 |
|------|------|--------|
| V1 | 主动查询 + 五要素 + 语义层 | 零 SQL 查数据 |
| V2 | 查询增强（Top N、两时段对比、派生指标、下钻） | 覆盖 90% 查询 |
| V3 | 主动推送（定时摘要 + 异常告警） | 数据找人 |
| V4 | 主动诊断（归因 + 行动建议） | 回答"为什么" |
